# 《西游记》西行路线与妖怪地图设计

## 学习目标

用地图辅助阅读《西游记》。孩子可以沿着故事顺序回顾师徒到了哪里、遇见了谁、故事发生在哪几回，也可以用玄奘的史实路线作对照，理解小说如何借用真实地理来展开想象。

## 页面与交互

- 桌面端左侧是按故事顺序排列的地点卡片，右侧是地图。手机端地图在上，地点列表在下。
- 地点卡片显示回目、现代地名参照、定位等级和相关角色。点击卡片会定位到地图节点。路线图层开启时，卡片也会打开详情。可直接点击可见的地图标记查看详情。
- 搜索会筛选地点列表。可用地点名、现代地名、回目、角色名或别名，也可以检索情节和角色说明。地图继续展示所选图层的完整内容。
- 默认显示蓝色故事路线与红色妖怪、绿色归队角色标记。可独立开关路线、角色标记和金色史实路线。重置视野会重新框住全部故事地点。
- 地图右上角可以切换底图，默认使用标准街道图。

## 内容与地理口径

故事路线参照通行百回本。页面收录 44 组地点，按情节顺序从长安串联到灵山。同一段故事中的地点可以合并为一组。角色条目主要记录有名有号的妖怪、重要精怪和可辨识的群体，也记录在途中加入队伍的角色。

| 标注 | 含义 | 示例 |
| --- | --- | --- |
| A | 有较明确的现实地理原型 | 长安参照今西安。 |
| B | 一种现代地理推定 | 车迟国采用塔什干一带的推定。 |
| C | 小说虚构或无法精确定位，点位用于展示行程 | 白虎岭使用区域示意点。 |
| B/C | 同一组兼有推定地点和文学示意地点 | 朱紫国有区域推定，麒麟山獬豸洞是小说地点。 |

蓝色折线按回目顺序连接示意点。金色路线是供对照的简化历史路线。更新现代地名参照时，优先记录具体出处，并保留对争议地点的说明。

## 实现与部署

- 专题入口 [index.html](../topics/xiyouji/index.html) 定义页面结构，[styles.css](../topics/xiyouji/styles.css) 定义页面样式。
- [map.js](../topics/xiyouji/map.js) 负责地图、地点列表和交互。地图使用 Leaflet，通过 MapLibre 的 Leaflet 适配层加载 OpenFreeMap 矢量底图。前端库从 unpkg 加载，页面保留 OpenFreeMap、OpenMapTiles 和 OpenStreetMap 署名。
- [data.js](../topics/xiyouji/data.js) 保存故事地点和史实对照。故事地点的 `places` 数组包含 `id`、地名、今地参照、经纬度、回目、定位等级、说明和 `demons` 角色列表。史实对照的 `historicalRoute` 数组每项格式为 `[纬度, 经度, 地点名称]`。
- Cloudflare Pages 将 `topics/` 作为站点根目录发布，线上通过 [https://kids-learning-hub-abq.pages.dev/xiyouji/](https://kids-learning-hub-abq.pages.dev/xiyouji/) 访问，对应路径 `/xiyouji/`。本地预览命令见[项目说明](../README.md#本地预览)。
- 底图和前端库通过网络加载。地图空白时，可在浏览器开发者工具的网络面板检查 unpkg 和 OpenFreeMap 请求。

## 更新后核对

1. 核对回目、故事顺序和角色归属。新增地点时使用唯一的 `id`，并同步检查页面顶部的地点总数。
2. 用地点名和妖怪别名各测试一次搜索，检查卡片定位、详情弹窗和史实路线开关。
3. 在窄屏和宽屏分别查看地图与列表。若修改部署路径，在本地预览中直接打开 `/xiyouji/`。
