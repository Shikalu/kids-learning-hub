资料口径与使用说明：地点及妖魔出场顺序以《西游记》通行百回本的故事地理表为线索；现代地理参照综合公开路线研究中的一种对应方案。不同研究者对“两界山、流沙河、车迟国、狮驼国”等定位并不一致，故地图不把推定写成定论。无名小妖、妖兵不逐个定位；能辨识的主要妖怪、重要精怪及有名有号的小妖尽量列出。
底图服务：OpenFreeMap（开放源码、公开实例免注册免 API Key）；地图数据来自 OpenStreetMap，地图样式基于 OpenMapTiles。署名：OpenFreeMap · © OpenMapTiles · Data from © OpenStreetMap contributors。
